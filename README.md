### 💻 Projetos

Ao longo da graduação, desenvolvi projetos acadêmicos e pessoais com foco na melhoria da **lógica de programação, desenvolvimento de software, organização de código, versionamento e modelagem de banco de dados**.

Entre os principais projetos destacam-se:

**• Site de Bazar Solidário para Causa Animal**

– Desenvolvimento de uma aplicação web utilizando **HTML, CSS e JavaScript**, criada para divulgar produtos e incentivar arrecadações em apoio a uma causa de proteção animal. O projeto proporcionou experiência na construção de interfaces responsivas, manipulação do DOM e organização do código em JavaScript.

**• API de Produtos**

– Desenvolvimento de uma API REST para gerenciamento de tarefas, utilizando Node.js e Express, com integração a banco de dados relacional MySQL. O projeto envolve implementação de operações CRUD (Create, Read, Update e Delete), criação e organização de rotas HTTP, manipulação de requisições e respostas JSON, operações assíncronas com Async/Await e tratamento de erros com Try/Catch..

**• Sistema de Gerenciamento de Eventos em C**
*Projeto Acadêmico – IFSP*

– Desenvolvimento de um sistema para gerenciamento de dados utilizando a linguagem **C**, aplicando conceitos de lógica de programação, estruturas de dados, modularização e boas práticas de desenvolvimento.

**• Sistema de Biblioteca Universitária**
*Em desenvolvimento*

– Aplicação desenvolvida com **JavaScript, Node.js e SQL**, destinada ao gerenciamento de livros, usuários e empréstimos. O projeto contempla modelagem de banco de dados relacional, consultas SQL, organização modular da aplicação, versionamento com Git e aplicação de boas práticas no desenvolvimento **back-end**.
